# Breakout: Peer Resume Review (ungraded)

Bring a resume draft if you have one. If you do not, bring a blank document and the jobs, classes, projects, tools, and software you would put on it.

We'll spend about twenty minutes in pairs. Swap. Each person names one thing that is unclear and one thing that is missing. Not graded. You leave with two edits to make.
